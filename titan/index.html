Titan

An AI-native terminal for macOS.
Shells on a real terminal and Claude Code sessions as a readable feed, side by side in tabs and splits.
Built on libghostty, the terminal core behind Ghostty.

↓ See what it does

A personal project · macOS 26+ · Apple Silicon

-- why a terminal built around agents

Claude Code's TUI takes over a whole terminal: its own transcript, its own input box, its own spinners. Run three of them and you're flipping through tabs to find the one that's waiting on you. Titan runs Claude Code in its structured stream mode instead, so a session is a pane like any other, and Titan knows what each one is doing.

A feed, not a screen scrape

Replies, tool calls and their output arrive as messages. Titan sets replies as Markdown for reading, folds tool output until you open it, and never scrapes text off a screen.

Know which session needs you

Tabs show whether their Claude sessions are working, done or waiting on you. ⌘J jumps to the one that's waiting; hover a tab to see what each session is doing.

Sessions outlive the window

Shells and Claude sessions run in titan-ptyd, a small daemon, so quitting or updating Titan doesn't stop them. Reopen it and they're where you left them.

-- the claude pane

⌘N starts a Claude Code session in a folder you pick. It's the same claude you already use, with your settings, CLAUDE.md, skills and MCP servers, drawn as a conversation with an input box of its own.

A welcome to start from

A new session opens on Titan's infinity, drawn in dots in your theme's colours, with ⌘P and your latest recipes a click away.

Send while it works

↩ sends at once, and Claude takes the message in at the running turn's next step. ⌥↩ queues it for when the turn ends instead.

Run what it suggests

Shell code blocks in a reply get Run, Run in a shell and Copy. Output streams in under the block. Nothing runs without the click.

See what changed

/diff and /git open a side pane with every file changed since the session started, plus git status, recent commits and stashes.

Pages, live in the feed

HTML and SVG files Claude writes show up in the conversation as live pages, scripts and styles included, and move down as Claude revises them.

A browser it can drive

⇧⌘B opens a browser pane beside the conversation. Claude can load, read and click through a page, your dev server included, while you watch.

Every path is a link

File paths and URLs in the feed are clickable. A file opens beside the pane at its line, in a built-in viewer or your $EDITOR.

A worktree each

⇧⌘N starts a session in a git worktree of its own, so two sessions can work on one repository without stepping on each other.

Model, effort, context

A model picker, an effort slider and a ring for how full the context window is. Permission modes run from asking every time to YOLO.

@ and /

@ fuzzy-finds files to mention. / lists the commands and skills installed for that session, with their descriptions.

Attach anything

Paste or drop images and files into a conversation, or drop them on a tab: a Claude session attaches them, a shell types their paths.

-- and a real terminal

libghostty inside

The same VT core as Ghostty, drawn with Metal. Improvements upstream arrive as a rebuild, not a rewrite.

Tabs and splits

⌘D and ⇧⌘D split, ⇧⌘↩ expands a pane. Drag panes onto tabs, tabs out into windows, and ⌘E shows every tab at once.

Command palette

⌘P reaches every command, resumes past Claude sessions, opens lazygit, and starts recipes: saved setups of shells and a browser that ask for what they need first.

Claude's TUI works too

Prefer claude in a shell? Run it in a pane and it still gets Titan's notifications, keep-awake and browser.

More than one Claude account

Map folders to Claude accounts and each session opens under the right one, its history kept apart. Continue a session under the other account in one click.

Your colours, everywhere

A theme reaches the whole window, the Claude pane, and Neovim running inside it.

-- one config file

# ~/.config/titan/config
font-family = JetBrains Mono
font-size = 14
tab-position = left
reading-width = 95
file-links = editor
keep-awake = true

# folders to Claude accounts
claude-account = Personal, ~/.claude
claude-account = Client, ~/.claude-client, ~/code/client

Ghostty's settings, then Titan's

Titan reads your Ghostty config first and its own on top, so fonts, themes and colours you've set up carry over. ⌘, opens the file, and Titan reloads it when you save.

Uses your Claude Code login

Claude panes run the Claude Code CLI you have installed, signed in with your own account. There's no API key to paste into Titan. Without Claude Code, shells work as usual.

-- faq

Why only macOS?
Titan is a native Mac app: SwiftUI and AppKit for the window, Metal for drawing, Liquid Glass from macOS 26. Its terminal core, libghostty, runs elsewhere, but everything around it is written for the Mac. There are no plans for Linux or Windows.
Can I download it?
Not yet. Titan is a personal project and there's no public build. It needs macOS 26 (Tahoe) on Apple Silicon, and Claude Code for its Claude panes.
Does it need an API key?
No. Titan runs the Claude Code that's installed, so sessions use the account it's signed in with and count against that plan as usual.
Does it change how Claude Code behaves?
Barely. It's the same CLI with your settings, skills and MCP servers. Titan adds one short note to the system prompt so Claude knows that pages show up in the feed and how to write paths that link.
Where are my conversations?
Where Claude Code keeps them, in ~/.claude/projects. Titan reads them for its history list and to resume sessions, and they work in the plain claude TUI as well.
