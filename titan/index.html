Titan

01 feed

Claude Code, set for reading.

Markdown replies, folded tool calls, permissions inline. A conversation, not a screen scrape. A new session opens over liquid glass, in your theme's colours.

02 status

Know which agent needs you.

  • ▶ working
  • ● needs you
  • ● done
  • ○ idle

⌘J jumps to the one that's waiting. ⌘E shows them all.

03 browser

A browser your agent can drive.

It opens your page beside the conversation, reads it and clicks through it.

05 pane limits

Agents keep to their own panes.

They use the panes they open. For yours, Titan asks you first.

06 review

Every change, in one pane.

/diff lists every file the session touched, with git status beside it.

07 fork & handoff

Branch it. Hand it off.

/fork tries another approach while the conversation carries on. /handoff starts fresh with only what the goal needs.

sessions · ~/code/pomodoro
● Fix the timer drift  · context 71%
├─ ⑂ /fork try it with requestAnimationFrame
│    the same history, a branch of its own
└─ → /handoff ship the fix and a test
     a fresh session, the brief in its composer

↳ Handed off from “Fix the timer drift”

Past 60% of the context, Titan compacts a copy in the background and moves the session onto it at its next pause.

08 actions

Every command is an action.

Bind it to a key, run it with titan do, or let an agent run it.

09 themes

Your theme, everywhere.

Titan reads your Ghostty config. Pick a theme and it spreads across the window from the corner: panes, glass and all.
